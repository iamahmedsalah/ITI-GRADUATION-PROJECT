# ILMA Features Inventory

This document is a feature-by-feature inventory of the current codebase. It separates working implementation from partial, placeholder, planned, and missing areas.

## Feature Status Legend

| Status      | Meaning                                                                              |
| ----------- | ------------------------------------------------------------------------------------ |
| Working     | Implemented end to end and visible in code paths.                                    |
| Partial     | Present but incomplete, scaffolded, or not fully productized in UI/integration.      |
| Placeholder | A route/page/model exists, but the actual feature is not yet connected or finalized. |
| Planned     | Mentioned in product context or architecture notes, but not integrated in this tree. |
| Missing     | No meaningful implementation was found in the inspected repository.                  |
